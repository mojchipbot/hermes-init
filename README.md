# Hermes Control Panel

A TypeScript/React web interface for Hermes credits and model management.

## Features

- **Fetch Credits**: View current credit usage
- **Model Selection**: Choose from available LLM models
- **GitHub Pages Deployment**: Static hosting ready

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This will build the project and deploy to `https://mojchipbot.github.io/hermes-init/`
